# Arduino Breadboard Bootloaders

Board definitions and an 8 MHz bootloader for running an ATmega328P on a breadboard with no external components, using its internal clock.

Pick the files that match your Arduino IDE version:

| IDE version | Folder | Zip download |
| --- | --- | --- |
| 1.6.x and newer | `ide-1-6-x/` | [breadboard-1-6-x.zip](zips/breadboard-1-6-x.zip) |
| 1.5.x | `ide-1-5-x/` | [Breadboard1-5-x.zip](zips/Breadboard1-5-x.zip) |
| 1.0.x | `ide-1-0-x/` | [Breadboard1-0-x.zip](zips/Breadboard1-0-x.zip) |

Copy the `breadboard` folder into the `hardware` folder inside your Arduino sketchbook, then restart the IDE.
